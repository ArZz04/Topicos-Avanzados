## Introducción

En esta práctica se desarrolló un programa en C# para gestionar las calificaciones de un alumno. El sistema permite registrar las calificaciones de tres materias y realizar diferentes operaciones mediante funciones independientes.

El programa permite calcular el promedio de las calificaciones, identificar la calificación más alta y más baja, así como determinar si el alumno aprobó o reprobó el curso de acuerdo con su promedio.

Además, se implementó un menú de opciones que permite al usuario interactuar con el programa de manera sencilla y controlar el acceso a las diferentes operaciones dependiendo del estado de las calificaciones registradas.

#### Enunciado

Crear un programa en C# que solicite al usuario las calificaciones de tres materias y utilice funciones independientes para calcular el promedio, obtener la calificación más alta, obtener la calificación más baja y determinar si el alumno aprobó o reprobó el curso.

El programa deberá considerar que una calificación aprobatoria es aquella cuyo promedio sea mayor o igual a 70, mientras que un promedio menor a 70 representa una calificación reprobatoria.

Además, el sistema cuenta con un menú que permite registrar las calificaciones, calcular y consultar los resultados correspondientes.

Fuente: `DOCENTE`

#### Código

El programa fue desarrollado utilizando diferentes clases para separar las responsabilidades de cada operación.

La clase principal `CU` se encarga de controlar el menú y llamar a los métodos correspondientes.

La clase `Register` se encarga del registro de las calificaciones.

La clase `CalcProm` realiza el cálculo del promedio.

La clase `ShowProm` muestra el promedio obtenido.

La clase `CalHigh` obtiene la calificación más alta.

La clase `CalLow` obtiene la calificación más baja.

Finalmente, la clase `SuccessCourse` determina si el alumno aprobó o reprobó el curso.

La cantidad de materias se configura directamente en el código mediante la variable `n_Cals`, permitiendo modificar fácilmente la cantidad de calificaciones que manejará el programa.

#### Conclusiones

En el desarrollo de esta práctica se logró aplicar el concepto de funciones o métodos en C#, utilizando diferentes métodos para realizar cada una de las operaciones solicitadas.

También se trabajó con arreglos para almacenar las calificaciones y con estructuras de control como `if` y `for` para procesar la información. Además, se implementaron variables booleanas para controlar el estado del programa y determinar qué opciones del menú pueden utilizarse en cada momento.

La separación del programa en diferentes clases permitió mantener el código organizado y asignar una responsabilidad específica a cada archivo. De esta manera, el archivo principal se encarga principalmente de controlar el menú, mientras que las demás clases realizan las operaciones correspondientes.

Finalmente, se implementó una validación para evitar el registro de calificaciones fuera del rango de 0 a 100 y se estableció que un promedio mayor o igual a 70 representa la aprobación del curso.
