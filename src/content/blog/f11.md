## Introducción

En esta práctica se desarrolló un programa en C# para calcular los primeros $n$ factoriales de un número entero positivo ingresado por el usuario. El sistema procesa la solicitud mediante una función independiente y muestra la secuencia iterativa formateada en consola.

El programa valida que el número introducido por el usuario sea un entero positivo mayor a cero para garantizar la correcta ejecución del cálculo.

Además, la implementación de la función permite realizar el procesamiento del factorial de manera aislada al flujo principal del programa, promoviendo la modularización del código.

#### Enunciado

Realizar un programa que calcule los primeros $n$ factoriales de un número entero solicitado por teclado al usuario.

Por ejemplo, si el usuario introduce 5, el programa deberá mostrar:
- 1! = 1
- 2! = 2
- 3! = 6
- 4! = 24
- 5! = 120

El cálculo del factorial deberá realizarse mediante una función.

#### Código

El programa fue desarrollado utilizando una estructura modular en C#.

La clase principal `Program` se encarga de gestionar la interacción con el usuario, la entrada y validación de datos por teclado, y la impresión de la secuencia formateada.

La función independiente `CalcularFactorial` recibe un número entero como parámetro y devuelve el resultado del factorial de tipo `long` para manejar valores numéricos grandes y prevenir desbordamientos.

#### Conclusiones

En el desarrollo de esta práctica se aplicó el concepto de funciones independientes con retorno de valores en C#, separando la lógica del cálculo matemático de la interfaz de consola.

Se trabajó con estructuras iterativas for para realizar el producto acumulado del factorial y con un ciclo do-while junto a int.TryParse para asegurar que el dato ingresado fuera un entero positivo válido.

Finalmente, se comprendió la importancia del uso de tipos de datos con mayor espacio en memoria como long al tratar con funciones de crecimiento rápido como el factorial.
