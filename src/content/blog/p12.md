# 1. Introducción

En la presente práctica se desarrolló una aplicación de escritorio utilizando el lenguaje de programación **C#** y el framework **Avalonia UI**, con el objetivo de transformar diferentes ejercicios que originalmente podían ejecutarse mediante una interfaz de consola en una aplicación con una interfaz gráfica interactiva.

El proyecto integra principalmente tres ejercicios:

* Cálculo de factoriales.
* Registro y análisis de calificaciones.
* Cálculo de las raíces de una ecuación cuadrática.

Cada ejercicio fue integrado dentro de una misma aplicación, permitiendo al usuario navegar entre las diferentes funcionalidades mediante una interfaz organizada con un menú lateral.

Además de resolver los problemas matemáticos planteados, la práctica permitió aplicar conceptos relacionados con la programación orientada a objetos, métodos, validación de datos, estructuras de control, arreglos y separación de responsabilidades dentro de un proyecto de software.

La implementación mediante Avalonia UI permitió comprender la diferencia entre un programa tradicional de consola y una aplicación basada en eventos, donde las acciones del usuario, como presionar un botón, generan la ejecución de diferentes métodos y procesos.

---

# 2. Objetivo general

Desarrollar una aplicación de escritorio utilizando **C# y Avalonia UI** que permita resolver diferentes ejercicios mediante una interfaz gráfica, aplicando validación de datos, estructuras de control, métodos y separación de la lógica de negocio respecto a la interfaz de usuario.

---

# 3. Objetivos específicos

* Implementar una interfaz gráfica utilizando Avalonia UI y archivos AXAML.
* Adaptar programas originalmente desarrollados para consola a una aplicación gráfica.
* Implementar el cálculo de los primeros factoriales de un número determinado.
* Registrar una cantidad variable de calificaciones y calcular su promedio.
* Identificar la calificación más alta y la más baja.
* Determinar si un alumno aprobó o reprobó de acuerdo con su promedio.
* Resolver ecuaciones cuadráticas mediante el cálculo de su discriminante.
* Identificar los diferentes tipos de soluciones de una ecuación cuadrática.
* Validar los datos introducidos por el usuario.
* Separar la lógica de negocio de los componentes relacionados con la interfaz gráfica.
* Implementar navegación entre diferentes vistas dentro de una misma aplicación.

# 4. Herramientas y tecnologías utilizadas

Para el desarrollo de la práctica se utilizaron las siguientes herramientas y tecnologías:

* **Lenguaje:** C#
* **Framework:** .NET
* **Framework de interfaz gráfica:** Avalonia UI
* **Lenguaje de marcado:** AXAML
* **Entorno de desarrollo:** Visual Studio Code
* **Sistema operativo de desarrollo:** macOS

La aplicación fue ejecutada utilizando el comando:

```bash
dotnet run
```


Avalonia UI permite desarrollar aplicaciones gráficas utilizando una estructura basada en archivos AXAML para la interfaz y archivos C# para la lógica y comportamiento de los componentes.

La estructura general del proyecto se organizó de manera similar a la siguiente:


## 6.1 Menú lateral de navegación

Para facilitar el acceso a cada uno de los ejercicios se desarrolló un componente denominado **Sidebar**.

Este componente contiene botones que permiten navegar hacia las diferentes vistas disponibles dentro de la aplicación.

Entre las opciones principales se encuentran:

* Dashboard
![Recurso placeholder](/p12/Dash.png)

* Factorial
![Recurso placeholder](/p12/facto.png)

* Calificaciones
![Recurso placeholder](/p12/cals.png)

* Raíces
![Recurso placeholder](/p12/faices.png)

* Clase
![Recurso placeholder](/p12/Ppepeltoro.png)

Cada botón utiliza eventos `Click` para ejecutar el método correspondiente en el archivo de lógica del componente.

Ejemplo:

```xml
<Button Classes="menuButton"
        Content="Factorial"
        Click="Factorial_Click"/>
```

```xml
<Button Classes="menuButton"
        Content="Calificaciones"
        Click="Calificaciones_Click"/>
```

```xml
<Button Classes="menuButton"
        Content="Raices"
        Click="Raices_Click"/>
```


También se implementaron estilos para proporcionar una apariencia uniforme a los botones del menú.

```xml
<Style Selector="Button.menuButton">
    <Setter Property="HorizontalAlignment" Value="Stretch"/>
    <Setter Property="Foreground" Value="#383838"/>
    <Setter Property="Background" Value="#CECECE"/>
    <Setter Property="Padding" Value="12"/>
    <Setter Property="HorizontalContentAlignment" Value="Left"/>
</Style>
```
